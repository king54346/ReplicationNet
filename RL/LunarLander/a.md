# LunarLander 得分计算

## 总公式

$$\text{总得分} = \text{位置/速度奖励} + \text{腿接地奖励} + \text{燃料消耗惩罚} + \text{降落/坠毁奖惩}$$

---

## 1. 位置与速度（势函数 Shaping）

每步奖励来自势函数的**差值**，衡量飞船是否在"变好"：

$$r_{\text{shaping}} = \phi_t - \phi_{t-1}$$

$$\phi = -100\sqrt{x^2 + y^2} - 100\sqrt{v_x^2 + v_y^2} - 100\,|\theta|$$

| 分项 | 含义 |
|------|------|
| $-100\sqrt{x^2+y^2}$ | 离平台越远扣越多 |
| $-100\sqrt{v_x^2+v_y^2}$ | 速度越快扣越多 |
| $-100\,\|\theta\|$ | 倾斜角越大扣越多 |

> 靠近平台、减速、摆正姿态 → $\phi$ 增大 → 正奖励

### 示例

**第 1 步**：$x=0.1,\ y=0.8,\ v_x=0.1,\ v_y=-0.3,\ \theta=0.05$

$$\phi_1 = -100\times0.806 - 100\times0.316 - 5 = -117.2$$

**第 2 步**：$x=0.1,\ y=0.6,\ v_x=0.05,\ v_y=-0.2,\ \theta=0.02$

$$\phi_2 = -100\times0.608 - 100\times0.212 - 2 = -84.0$$

$$r_{\text{shaping}} = -84.0 - (-117.2) = \mathbf{+33.2} \quad\text{（靠近了平台且减速）}$$

---

## 2. 腿接地

每步、每条接地的腿各奖励 **+10**：

| 状态 | 每步奖励 |
|------|---------|
| 左腿接地 | +10 |
| 右腿接地 | +10 |
| 双腿接地 | +20 |

---

## 3. 燃料消耗

| 动作 | 每步惩罚 |
|------|---------|
| 主引擎（↑） | −0.30 |
| 侧引擎（←/→） | −0.03 |
| 不点火 | 0 |

---

## 4. 降落 / 坠毁（终局奖惩）

| 结果 | 奖励 |
|------|------|
| 成功降落（静止在平台） | **+100 ～ +140** |
| 坠毁 / 飞出边界 | **−100** |

> 终局奖惩**覆盖**当步所有其他奖励。

---

## 每步完整公式

$$r_t = (\phi_t - \phi_{t-1}) - 0.30\times\text{主引擎} - 0.03\times\text{侧引擎} + 10\times\text{接地腿数}$$

特殊情况下直接替换为 $\pm100$。

---

## 完整轨迹示例

| 步骤 | 奖励来源 | 奖励值 |
|:----:|---------|-------:|
| $r_1$ | 靠近平台 + 减速 − 主引擎 | +37.4 |
| $r_2$ | 继续靠近 + 减速 | +43.0 |
| $r_3$ | 接近平台 − 主引擎 | +42.9 |
| $r_4$ | 左腿接地 | +40.0 |
| $r_5$ | 飞船静止（成功降落） | +100.0 |
| **合计** | | **+263.3** |
